 [ ] Offline fight solver / planner   (added 2026-07-07)
------------------------------------------------------------------------
Goal: an offline tool that computes the OPTIMAL move sequence for a given
board of the Bolgrot fight, which I then play BY HAND.

Why not bot the real Dofus client:
  - Violates Ankama's Terms of Service (bannable, permanent).
  - Shared multiplayer world — affects other players.
  - Brittle: reading the live Unity client state is fragile.
  => This solver is the legitimate alternative: it only advises; I make
     the moves myself in the real game.

Plan:
  1. Make the simulator match the REAL Bolgrot mechanics precisely
     (spells, AP, flame spawn patterns, map). Verify against the fight.
  2. Add src/solver/ with an exact search over game states
     (minimax / expectimax / BFS). For a fixed turn-based puzzle boss an
     exact solver beats NEAT and is PROVABLY optimal.
  3. Output as advice, e.g. "jump west, then clear the NE flame".
     NOT automation of the live client.

Related: the NEAT AI already lives in src/ai/ (see CLAUDE.md).
