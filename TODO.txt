BOLGROT WEB — ROADMAP (guide mode: you code, I mentor)
================================================================================
Stack recommandé : FastAPI (backend Python) + Vue 3/Vite (front JS) + Canvas 2D.
Pourquoi : FastAPI expose ton Game/AZ en HTTP typé avec une doc auto (/docs) qui
te sert de banc de test AVANT d'avoir un front ; Vue 3 + Vite = dev rapide, et le
board iso se dessine au Canvas (le Renderer pygame ne se transporte pas, mais la
projection iso est 2 lignes de maths — je te guide).

Règle du jeu : à chaque tâche je t'explique le concept + les pièges, tu écris le
code, on relit ensemble. Coche au fur et à mesure. [ ] = à faire, [~] = en cours,
[x] = fait.
